# Rowan Reach: Volume II — Fiddle First

## Motifs
- Rowan Call: `D4–F#4–A4–B4–A4–F#4`; lead fiddle, held summit on B, falling answer.
- Hearth Answer: `F#4–E4–D4`; mountain dulcimer, quietly completes the unresolved Rowan phrase.
- Working Hands: `A4–E4–F#4–A4`; rhythmic mandolin/craft motif.
- World motif: `D4–A4–G4–E4–D4`; mostly cello or French horn.
- Banjo is an *accompaniment texture*, not a major melodic motif. Prefer quiet, damped clawhammer brush/thumb patterns underneath upright bass. Motifs and note numbers are compositional targets, not a verified guarantee of Suno generation.

## Defaults
Suno Pro, Custom, Instrumental ON. v6. Variety 0. Standard generation initially, Max selectively when refining longer cues or Covers. Use the shared Exclude below, without putting exclusions into individual Style prompts. Suggested starting parameters in each cue are exploratory, not official presets. Bracketed arrangement instructions in the Lyrics area are experimental: listen for compliance rather than assume the text controls the audio precisely.

### Shared Exclude

```text
vocals, singing, spoken word, chanting, choir, banjo solos, foreground banjo, fast three-finger banjo rolls, banjo shredding, treble-dominant banjo picking, high-volume banjo arpeggios, novelty hoedown, generic country jingle, cinematic trailer drums, braaams, EDM drops, synthesizer supersaws, frantic fiddle shredding, constant orchestral pads, sentimental piano ballad 
```

## Motif & production notes
- Target key/mode: D Mixolydian / D major-pentatonic core, with B-minor-colored shadow scenes. Occasional C natural may appear in harmony; the motif retains F-sharp unless an intentional variation is documented.
- Reference to Rohan: study *dramatic role* of the featured bowed lead and later horn transformation; do not borrow themes, melody, or precise harmonic sequencing. Keep Hardanger fiddle associated with Nordic/Fjordhaven palette rather than Rowan Reach.
- Banjo discipline: exclude the *solo/lead/highly-rolled* banjo but retain quiet clawhammer timekeeping when the cue explicitly calls for it. For a true no-banjo control, also add `banjo, five-string banjo, clawhammer banjo` to Exclude and remove it from the Style input.
- Studio 2.0 is Premier-only as of August 2026; on Pro, prefer direct v6/Cover/reference workflows and a separate DAW for exact MIDI scoring.

## Suggested test sequence
1. Generate two takes each for **Above the Rowan Canopy**, **The House at First Light**, and **Across Laurel Gap**; choose one where the fiddle's melody is identifiable without reading the prompt.
2. Compare 15–30 seconds of the first clear Rowan Call in each; log any changes in notes, contour, or phrasing.
3. Use the selected reference and Pro-accessible Cover (or v6 multi-reference Simple Mode) to request a contrasting arrangement while preserving the tune. Covers aim to preserve melody but are not guaranteed exact.
4. Run one clean no-banjo control, then restore soft clawhammer under the winning fiddle reference. This isolates whether the banjo prompt or the genre tag causes overemphasis.
5. Move to working-town pieces after the main melodic performance is acceptable. Finish with **A Thousand Hearths** and the encounter cue.
6. Check each output separately for fiddle-to-banjo prominence, recall of the culture theme, legibility of each secondary motif, dynamic arc, and retained gaps/silence. No success assumed from prompt alone.
